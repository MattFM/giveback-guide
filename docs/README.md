# Documentation

Reference and planning documents for Give Back Guide.

Nothing in this folder is part of the build. Astro uses the default `src/` and
`public/` directories (no `srcDir` override in `astro.config.mjs`), so this
folder is neither routed nor copied into `dist/`, and Pagefind only indexes the
built HTML.

## Contents

- [`plans/`](./plans/) — planning and strategy documents

## Adding to this folder

Keep documents in Markdown. One subject per file. Do not put anything here that
needs to be reachable as a URL on the live site — that belongs in `src/pages/`.
